# 冰上图鉴 ICE ATLAS

原生 HTML、CSS、JavaScript + Node.js / Express + MongoDB 的女子单人花样滑冰科普与交流平台。

## 本地运行

本机已安装依赖。在 VS Code 终端执行 `npm start`，然后在 Chrome 打开 http://127.0.0.1:3000 。如果旧服务正在运行，请先按 Ctrl+C 停止再重新启动，最后刷新网页。

复制到新电脑时，先运行 `npm install`，需要 Node.js 22.19+ 和 MongoDB。账号功能必须通过 Node.js 服务使用，不能直接双击 HTML 文件登录。

程序优先连接本机 MongoDB；若默认 27017 端口没有数据库，会尝试启动 PATH 中已安装的 mongod，数据写入当前项目的 `.data/mongodb`。已有数据库服务则直接复用，不修改其数据目录、不停止它。退出网站时关闭由网站自己启动的数据库进程。

可复制 `.env.example` 为 `.env` 设置 MongoDB 连接、数据库名或 mongod 路径。本机已检测到 E:/MongoDB/bin/mongod.exe；若终端未继承 PATH，可设置 `MONGOD_PATH=E:\MongoDB\bin\mongod.exe`。

## 赛事动态同步

Node.js 启动后每 6 小时检查 ISU 本赛季成绩，MongoDB 的 `season_cache` 保存最近成功结果；浏览器每分钟读取缓存。只有完整的女单分类总成绩（短节目和自由滑名次均存在）才生成领奖台，网络失败时保留已核实的数据。已公布的 9 场赛事均已核实前三名总分。服务停止期间不会执行同步。

需要立即检查官方成绩时，在 VS Code 终端运行 `npm run sync`。赛事页的“刷新页面数据”按钮读取后端缓存，不触发对 ISU 的全量抓取。此功能更新赛程与领奖台成绩，运动员照片、历史简介及赛事背景图片属于人工核实的素材快照。

世界积分榜在 Node.js 启动后立即检查，此后每小时检查两份 ISU 榜单；浏览器每分钟读取 MongoDB 的 `rankings_cache`。页面分别显示官方榜单更新时间和本站最近成功同步时间（UTC+8）。可点击“立即与 ISU 同步”直接检查官方榜单（每分钟最多 2 次），或运行 `npm run sync:rankings`。网络失败、榜单类别不匹配、过旧或明显截断的页面均保留原缓存。项目自带 2026-11-05 核实的完整快照，首次断网启动也能展示。服务停止时不执行同步，此功能是定时检查，不是官方推送。

积分采用官方总数，不根据页面分项重新计算，括号内未计入的分值保持原始数据。排名页只显示名次、姓名、国家与积分；已收录选手可跳转本站简介，其余有档案的选手可打开 ISU 个人档案。

运行 `node scripts/collect-career-medals.js` 可重新核对全部已收录选手的 ISU 生涯奖牌档案，更新后重启网站。读取失败会保留对应选手已有档案；它独立于本季每 6 小时自动同步。

网络请求可使用 `.env` 中的 `ISU_HTTPS_PROXY`。Windows 上也会读取已启用的现有系统代理，不更改系统设置。

## 接口

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| POST | /api/auth/register | 邮箱、昵称、密码注册，并自动登录 |
| POST | /api/auth/login | 邮箱与密码登录 |
| GET | /api/auth/me | 获取当前登录用户或 null |
| POST | /api/auth/logout | 销毁会话并退出 |
| GET | /api/forum/access | 返回读、发帖与回复权限状态 |
| GET | /api/forum/posts | 游客也可读取帖子 |
| POST | /api/forum/posts | 已登录用户可发布，游客返回 401 |
| GET | /api/season | 本季赛事缓存及合并后的选手简介、图片来源 |
| GET | /api/rankings?group=senior或junior | 对应组别积分榜缓存与同步状态 |
| POST | /api/rankings/sync | 立即检查两份官方榜单并返回最新缓存 |

写入接口需要同源 JSON 请求及 `X-Ice-Atlas: 1` 请求头。论坛详情接口 GET /api/forum/posts/:id，评论接口 POST /api/forum/posts/:id/comments；支持 category 和 page 参数查询帖子。

## 验证

- `npm run check`：JavaScript 语法检查。
- `npm test`：使用真实 MongoDB 检查账号权限及赛事缓存更新/失败保留，并校验官方结果解析、知识图示与分值。只操作独立的随机 `ice_atlas_test_*` 测试库，测试完成后自动清理。

## 文件

- `server.js`：配置、数据库连接和网站启动。
- `src/app.js`：Express 接口、会话和权限检查。
- `src/password.js`：密码哈希与校验。
- `src/local-mongo.js`：本机数据库检测与开发启动。
- `src/season.js`、`src/isu-fetch.js`：官方成绩解析、缓存更新及网络请求。
- `src/rankings.js`、`scripts/sync-rankings.js`：官方积分榜解析、每小时同步和手动同步。
- `public/rankings.js`、`public/rankings.css`：排名页、搜索筛选及分页。
- `data/`：已核实的赛程、个人简介与赛事照片来源。
- `public/auth.js`：前端账号请求、状态恢复及退出。
- `public/app.js`：页面切换、轮播、大图和排名分组。
- `public/learn.js`、`public/season.js`：科普、赛事、目录与个人简介页面。
- `public/content.css`、`public/readability.css`、`public/event-photos.css`：内容排版、文字清晰度和赛事照片背景。
- `public/styles.css`、`public/index.html`：页面外观与结构。
- `public/assets/`：正式照片与图标。

照片、项目数据和临时缓存保存在 D 盘项目中；临时下载与测试文件在完成后清理，运行必需素材和依赖保留。
